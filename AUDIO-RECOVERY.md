# Восстановление звука при смене устройства Windows

Локальное исправление от 2026-10-08. Встроенный VLC повторно подключается к текущему устройству Windows после смены устройства вывода по умолчанию, отключения или возвращения активного устройства. Уведомления Windows обрабатываются через очередь UI с задержкой 600 мс, чтобы несколько событий одного переключения не вызывали подряд несколько восстановлений.

В настройках видео добавлена кнопка **«Восстановить звук»** для ручного повторного подключения. Восстановление затрагивает только звуковой выход: фильм, выбранная аудиодорожка, позиция, пауза и громкость сохраняются. Отключённый пользователем звук (громкость 0) остаётся отключённым. Если Windows временно не предоставляет устройство по умолчанию, восстановление ждёт следующего события устройства или ручного нажатия.

Подписка `IMMNotificationClient` только читает состояние Windows. Она не меняет системное устройство по умолчанию, системную громкость или настройки других приложений. События устройств записи и смены только устройства связи не перенастраивают выход плеера. После остановки фильма или уничтожения плеера отложенные события не запускают воспроизведение.

## Проверено

- Release и самостоятельная x64-сборка: без ошибок и предупреждений.
- `tools/testing/AudioRecoverySmoke`: 12 проверок пройдены. На двух доступных устройствах измерен реальный сигнал тестового VLC через WASAPI-сессию только своего процесса. Плеер направлялся на второй выход, после чего обработчик уведомления возвращал измеряемый сигнал на системный выход. Проверены сохранение фильма, дорожки, позиции, громкости, паузы и mute, возобновление звука после паузы, фильтрация посторонних событий и безопасность событий после остановки/Dispose.
- `tools/testing/PlayerUiSmoke`: 39 проверок пройдены, включая кнопку восстановления звука, громкость, состояние и позицию видео, компактную/расширенную панель еды и остальные элементы плеера.
- Готовый EXE с локальными компонентами: `--self-test` завершился с `success: true`; каталог показал 28 карточек, мост Lampa подключился, шифрованный профиль прошёл сохранение и чтение. В этой самопроверке фильм не запускался; воспроизведение и восстановление звука проверены отдельными тестами выше.

В аудиотесте подключение к Windows-уведомлениям было настоящим, а уведомление о смене устройства подавалось программно. Системное устройство Windows не переключалось; физическое переключение пользователем и субъективная слышимость отдельно не проверены. Измерение WASAPI подтверждает реальный сигнал VLC на указанных выходах.

Аудиотест воспроизводит тихий тестовый тон и требует доступного устройства вывода. Зависимость `NAudio.Wasapi` используется только тестовым проектом и не входит в приложение.

```powershell
./.tools/dotnet/dotnet.exe build tools/testing/AudioRecoverySmoke/AudioRecoverySmoke.csproj -c Release
./.tools/dotnet/dotnet.exe tools/testing/AudioRecoverySmoke/bin/Release/net10.0-windows10.0.17763.0/AudioRecoverySmoke.dll .cache/audio-recovery.json
```
