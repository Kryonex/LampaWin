# LampaWin

Windows-приложение с локальной Lampa, управляемыми Jackett и TorrServer и встроенным плеером на LibVLC. Пользователю не нужны Docker, установленный VLC, .NET SDK или ручное указание адресов серверов.

## Установка и использование

Запустите `LampaWin-Setup-win-x64.exe` и откройте LampaWin. Установка выполняется для текущего пользователя. При отсутствии Microsoft WebView2 установщик скачивает и устанавливает официальный runtime; для этого нужен интернет. Каталоги, поиск и источники также требуют подключения к интернету.

При первом запуске программа создаёт отдельный профиль, запускает локальные компоненты, автоматически подключает их к Lampa и пытается добавить источники Rutor, 1337x и Nyaa. Доступность стороннего источника зависит от его работы, сети и защиты от автоматических запросов. Ошибки источников показываются в окне «Источники» и не должны останавливать всё приложение. Учётные данные для закрытых трекеров автоматически не создаются.

Открывайте видео через раздел торрентов Lampa. Управление отображается поверх видео и плавно скрывается через три секунды бездействия. Движение мыши возвращает панель; одиночный клик по видео переключает паузу, двойной — полный экран. На паузе, при перемотке и открытых настройках панель остаётся видимой. Шестерёнка открывает выбор аудиодорожек и субтитров.

Space / K — пауза, J / L или стрелки влево / вправо — перемотка на 10 секунд, M — выключение звука, стрелки вверх / вниз — громкость, F / F11 — полный экран. Escape сначала закрывает настройки или полный экран, затем возвращает в каталог. Прогресс передаётся обратно в Lampa. Команда «Восстановить сервисы» доступна в нижнем меню «Сервисы».

При закрытии программы её дочерние процессы завершаются. Автозапуск Windows и системные службы не устанавливаются. HTTP-интерфейсы слушают только `127.0.0.1`; P2P-движок TorrServer использует сеть для получения данных. Брандмауэр и другие уже установленные серверы не перенастраиваются.

Настройки, история, конфигурации и ограниченные по размеру журналы находятся в `%LOCALAPPDATA%\LampaWin`. Снимок настроек Lampa зашифрован Windows DPAPI для текущего пользователя. Удаление приложения сохраняет пользовательские данные. Папка с журналами открывается из приложения.

## Совместимость

Сборка предназначена для Windows x64, начиная с Windows 10 1809. Windows ARM64 и 32-битная Windows отдельными сборками не поддерживаются. .NET и LibVLC входят в комплект. Фактические результаты проверок и оставшиеся ограничения фиксируются в `artifacts/VALIDATION.md`; минимальная версия ОС в требованиях не означает, что каждая версия Windows проверена на отдельной машине.

## Сборка

Используются .NET SDK 10, PowerShell, Node.js/npm и Git. Версии исходников и SHA-256 загрузок закреплены в `config/components.json`. Репозиторий использует NuGet.org через `NuGet.Config`.

```powershell
# SDK можно установить локально в .tools/dotnet.
powershell -NoProfile -ExecutionPolicy Bypass -File tools/packaging/Acquire-Components.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools/packaging/Build-Release.ps1
```

Перед сборкой убедитесь, что приватный SDK доступен как `.tools/dotnet/dotnet.exe`. Итоговые файлы: `artifacts/LampaWin-Setup-win-x64.exe` и `artifacts/LampaWin-win-x64-portable.zip`. Переносимая версия запускается через `LampaWin.exe`; WebView2 должен присутствовать на компьютере.

Jackett собирается из закреплённого исходника с узкими изменениями для запуска без административных прав. Lampa собирается из закреплённого исходника. Исходники, патчи и уведомления о лицензиях включаются в дистрибутив.

## Проверки разработчика

```powershell
& .tools/dotnet/dotnet.exe run --project tests/LampaWin.Tests/LampaWin.Tests.csproj -c Release
node tests/bridge.test.cjs
& .tools/dotnet/dotnet.exe run --project tools/runtime/Smoke/RuntimeSmoke.csproj -c Release
```

`tests/torrent_fixture.py` создаёт локальный BitTorrent-трекер и раздаёт небольшой синтетический MP4. Он используется для реальной проверки цепочки TorrServer → локальный шлюз → LibVLC → сохранение прогресса Lampa. Исходное видео создаётся ffmpeg; файл и его содержимое в дистрибутив не включаются. Desktop поддерживает `--self-test`, `--install-root`, `--data-root`, `--report`, `--fixture` и `--torrent-url` для изолированных проверок.

## Ограничения

Используйте приложение для контента, к которому у вас есть доступ. Сторонние каталоги и трекеры могут менять API, ограничивать автоматические запросы или временно быть недоступными. Кодовая подпись для EXE требует отдельного сертификата издателя; локальная сборка не подписана и Windows может показывать предупреждение о неизвестном издателе. Отсутствие найденных дефектов в перечисленных проверках не является гарантией отсутствия всех возможных ошибок.

### Проверка управления поверх VLC

`tools/testing/PlayerUiSmoke` запускает реальное окно плеера за пределами экрана без запуска серверов. Проверяются отдельный слой над нативным VLC, скрытие и появление панели, пауза, перемотка, звук, меню дорожек, раскладка на двух ширинах и возврат в каталог.

```powershell
& .tools/dotnet/dotnet.exe run --project tools/testing/PlayerUiSmoke/PlayerUiSmoke.csproj -c Release -- .cache/fixture.mp4 .cache/player-ui-smoke/report.json
```
