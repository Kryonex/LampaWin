# LampaWin 2.0.3

Ускорены запуск и завершение приложения, включая первый запуск после установки.

- Видеодвижок VLC загружается при первом открытии видео. Для каталога, настроек и выхода без просмотра загрузка плеера не требуется.
- Сохранённые громкость, аудиовыход и настройки превью применяются при создании плеера.
- Каталог запускается параллельно с Jackett/TorrServer; источники поиска настраиваются в фоне. Проверка обновлений начинается после открытия каталога.
- При выходе окно сразу скрывается, потоки и запросы отменяются, а VLC освобождается в фоне. Для зависшего нативного компонента действует предел завершения в 6 секунд.
- Повторный запуск во время закрытия ждёт предыдущий экземпляр вместо активации закрывающегося окна.
- Профиль и настройки сохраняются в прежнем каталоге пользователя.

Проверки включают настоящие процессы приложения: выход во время запуска, открытие каталога без загрузки VLC, повторный запуск и выход при воспроизведении локального видео. Дополнительно проверяются отмена бесконечного видеопотока, восстановление отдельных локальных служб и существующий интерфейс плеера.
